This repository contains my Day 4 practical laboratory work for the Generative AI for Business course as a BBA Aviation Management student. The activity focuses on building effective and structured prompts using four essential ingredients: Task, Context, Constraints, and Output Format.

The lab demonstrates how vague and incomplete prompts can produce unclear or less useful AI-generated responses. It explores how adding relevant aviation information, specific instructions, limitations, and a suitable output format can improve the quality, relevance, clarity, and usability of AI responses.

The project includes a comparison between a vague flight-delay prompt and a structured prompt based on a realistic aviation scenario. It also covers converting a messy business request related to passenger baggage complaints into a clear and testable prompt. Additional aviation prompt-building challenges include flight cancellation communication, airport service surveys, social-media campaigns, staff training, and complaint classification.

The activity also includes peer review, prompt revision, and a one-variable testing exercise to understand how changing a single prompt component can affect the AI output. Reflection questions help evaluate the importance of prompt design and whether structured prompts can guarantee factual accuracy.

This work demonstrates practical prompt-engineering skills and responsible Generative AI usage for aviation-management and business communication tasks.
LAB 5
This repository contains my Day 5 practical laboratory work for the Generative AI for Business course as a BBA Aviation Management student. The activity focuses on iterative prompting and improving AI-generated outputs through a structured sequence of targeted follow-up prompts.

The lab demonstrates the process of Generate, Evaluate, Diagnose, Repair, Review and Approve. It uses aviation scenarios such as flight-delay announcements and passenger baggage complaints to identify factual, contextual, tone, compliance and communication problems in AI-generated responses.

The project includes an initial AI-generated output, a detailed diagnosis, and a prompt-refinement trail showing how each follow-up instruction addresses a specific problem. The activity focuses on correcting verified flight information, removing unsupported compensation or policy claims, adding passenger instructions, improving professional tone, controlling response length and using verification safeguards when information is missing.

A second iteration challenge examines an AI-generated baggage response containing unsupported delivery promises, compensation amounts and upgrade commitments. Targeted prompts are used to remove these unsupported claims and create a safer passenger response.

The lab also includes an original iteration relay, peer review, final-output comparison and reflection questions. This work demonstrates how aviation-management students can use iterative prompting responsibly while recognising that important aviation communications still require human review and approval.
